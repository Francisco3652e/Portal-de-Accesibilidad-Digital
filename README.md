# Portal de Accesibilidad Digital

Prototipo del programa gubernamental "Tecnología para Todos" (El Salvador), presentado como propuesta de licitación pública para la materia de Ética Profesional.

## Documento de la propuesta

Ver [`DOCUMENTO-JUSTIFICATIVO.md`](./DOCUMENTO-JUSTIFICATIVO.md): objeto de la licitación, marco ético (Justicia y Solidaridad), impacto social, checklist de cumplimiento WCAG 2.1 AA, cronograma, presupuesto referencial y guion de exposición (7–10 min).

## Páginas del prototipo

- `index.html` — Inicio
- `acerca.html` — Acerca del Proyecto
- `servicios.html` — Servicios
- `lector.html` — Lector de Pantalla (sección temática)
- `senas.html` — Lengua de Señas Salvadoreña / LESSA (sección temática)
- `contacto.html` — Contacto
- `ajustes.html` — Ajustes de accesibilidad (alto contraste, daltonismo, tamaño de texto, navegación guiada)

Abrir `index.html` directamente en el navegador para ver el prototipo; no requiere build ni dependencias (Tailwind se carga vía CDN).
